# Markdown Documentation

This directory contains all markdown documentation files organized by category.

## Directory Structure

- **active/** - Current, actively maintained documentation
- **validation/** - Validation documentation and instructions
- **test_validation/** - Test validation files (moved from `tests_validation/`)
- **archive/** - Historical/old documentation files

## Key Files

### Active Documentation
- `README.md` - Main project README (kept in root)
- `CHANGELOG.md` - Version history (kept in root)

### Validation Documentation
- `validation/VALIDATION_INSTRUCTIONS.md` - Step-by-step validation instructions
- `validation/VALIDATION_PROCESS.md` - Comprehensive validation process guide
- `validation/TEMP_VALIDATION.md` - Current validation checklist
- `validation/START_VALIDATION.md` - Quick start guide

### Test Validation
- `test_validation/README.md` - Test validation overview
- `test_validation/test_*.md` - Expected results for each test file

## Note

Some markdown files remain in their original locations:
- `README.md` - Root directory (standard location)
- `CHANGELOG.md` - Root directory (standard location)
- `tests/README.md` - Tests directory (co-located with tests)
- `cpp-tools/cfg-exporter/README.md` - Tool-specific README
